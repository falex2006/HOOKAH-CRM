### 4. Подтвердить сквозные бизнес-цепочки и матрицу ролей

Используй синтетическое тестовое заведение и отделяй настоящие PostgreSQL/браузерные проверки от моков.

- Склад: поставка → остаток и совместимые единицы → техкарта/премикс → продажа → ровно одно автосписание → зафиксированная себестоимость → валовая прибыль.
- Персонал: график → фактическое время → расчёт периода → утверждение → выплата → расход; проверь границы дат, пересечение периода, повтор выплаты и связь с финансами.
- Касса: открытие и начальный остаток → способы оплаты → ожидаемая сумма → пересчёт → расхождение → чек-лист и X/Z → безопасное закрытие.
- Финансы: выручка − себестоимость − зарплата − операционные расходы; закупка не должна второй раз уменьшать управленческую прибыль при продаже.
- Права: для каждой роли проверь боковую навигацию, видимость элементов, разрешённые/запрещённые действия и прямые API-маршруты. Скрытое кнопкой действие обязано быть запрещено сервером.
- Исправляй только подтверждённые сбои и не меняй спорные бизнес-правила без требования или достоверного основания.
