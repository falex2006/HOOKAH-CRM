# Сетевая схема HOOKAH POS

Единая внешняя точка входа приложения: `http://212.192.0.58/` через HTTP-порт `80`.

- POS: `http://212.192.0.58/`
- SaaS-панель: `http://212.192.0.58/platform`
- CRM API: внутренний порт контейнера `3000`, наружу не публикуется
- Внешний порт `8080` не используется и не должен добавляться в ссылки, инструкции или конфигурацию

Nginx принимает запросы на порту `80` и проксирует их в контейнер `crm` по внутреннему порту `3000`. SaaS и POS являются маршрутами одной актуальной CRM-сборки, поэтому для них не создаются разные IP или случайные внешние порты.

При деплое проверять:

```bash
ss -ltnp | grep ':80'
curl -i http://127.0.0.1/api/health
```

Ожидается один внешний listener на `0.0.0.0:80` и ответ `HTTP 200` от `/api/health`.
