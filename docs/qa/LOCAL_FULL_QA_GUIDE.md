# Полный локальный QA

Контур создан для запроса от 01.10.2026. Checkout: `HOOKAH CRM 2-reconcile`, ветка `codex/local-full-qa-20261001`. Исходный грязный checkout и прежние локальные сервисы сохранены. Публикация выполняется следующим отдельным этапом.

## Запуск

Нужны существующие Node.js, npm dependencies и Docker Desktop. Выполнять из корня этого checkout:

```powershell
npm run qa:local:setup
npm run qa:local:serve
```

Приложение: http://127.0.0.1:31932/ . Авторизация включена, статический demo выключен. `serve` занимает терминал; повторный экземпляр на этом порту запускать не нужно.

Оставьте сервер работающим, в другом терминале выполните `npm run qa:local:seed`. После первого наполнения остановите только этот serve процесс Ctrl+C и снова запустите `npm run qa:local:serve`: launcher возьмёт primaryVenueId из нового manifest. При повторной работе с уже наполненным контуром seed не обязателен.

Ignored `tmp/full-local-qa/runtime.json` хранит случайные локальные credentials. Ignored `tmp/full-local-qa/seed-manifest.json` хранит логины, ID и действия синтетических пользователей. Пароль владельца — `runtime.password`; пароль сотрудников с CRM-доступом — первые 10 символов этого значения. PIN синтетического сотрудника с CRM-доступом — `2468`. Кадровые карточки без CRM-доступа не получают credentials этой правкой. Эти файлы не включать в Git, архив выпуска или снимки экрана. Они не относятся к production.

## Данные и изоляция

База127.0.0.1:31930 сохраняется в именованном Docker volume. Два заполненных tenant, три точки, роли сотрудников и ограниченный администратор, залы/столы/VIP, каталог, ингредиенты, техкарты/премиксы, закупки/списания, гости/лояльность, брони/доставка, смены/заказы/платежи, расходы/начисления, задачи, аудит и уведомления. Seeder выполняет бизнес-действия через HTTP API и сохраняет manifest для повторного запуска.

Отдельная disposable база127.0.0.1:31931 предназначена для регрессий. Runner проверяет exact container name, label, PostgreSQL image, loopback port, тип volume и реальную DB identity. Регрессии не запускаются на сохраняемой базе31930. Дополнительные временные базы принадлежат runner и очищаются после прогона. Блокировка исключает одновременный запуск двух полных прогонов.

Миграция создаёт ещё пустую исходную организацию «Территория». Это не третья заполненная тестовая компания; seeder её не удаляет.

## Повторная проверка

```powershell
npm run qa:local:guards
npm run qa:local:full
```

Явные allowlists: `scripts/local-full-qa.mjs`. Параметры `--static`, `--memory`, `--postgres`, `--list` позволяют выбрать часть. Ошибка останавливает прогон с nonzero exit. Summary, sanitized logs и браузерные снимки сохраняются в ignored `tmp/full-local-qa/`.

Браузерный QA проводится отдельно: вход роли, переход, действие, обновление, повторное чтение и проверка ошибок. Сейчас проверены desktop1280×720 и1440×900; мобильная компоновка отложена пользователем.
