# Промт: типографика, текст и цифры Territory CRM

Перед изменением страницы проверь текстовый слой интерфейса. Используй Manrope как единый шрифт CRM. Строй иерархию в четыре уровня: заголовок страницы, заголовок блока, подпись поля и вспомогательное пояснение. Один экран должен иметь один главный заголовок и короткое описание без повторов.

Основные правила:

- Главный заголовок: 32–40 px, 700–800, line-height 1.08, короткая формулировка.
- Заголовок блока: 18–22 px, 700, line-height 1.2.
- Обычный текст и действия: 13–15 px, 500–600.
- Подписи, даты и подсказки: 11–12 px, 400–500, цвет вторичного текста.
- Не использовать капслок для обычных сообщений; капслок допустим только для коротких eyebrow-разделов.
- Денежные суммы, счётчики, количества и даты выравнивать табличными цифрами (`font-variant-numeric: tabular-nums lining-nums`), чтобы значения не прыгали при обновлении.
- Деньги выводить через единый формат `ru-RU` с пробелом между тысячами и символом ₽ после суммы. Не смешивать `руб.`, `рублей` и `₽` на одном интерфейсе.
- Нули показывать как `0 ₽`, отсутствие данных — как `—`; не заменять отсутствие данных нулём.
- На карточке сначала показывать значение, затем контекст: «Выручка сегодня», «Ожидается», «заказов без полной оплаты».
- Кнопка содержит действие («Открыть смену», «Сохранить»), а не статус. Статусы отображаются бейджами.
- Проверять переполнение на узких экранах: длинные имена и суммы переносятся аккуратно, важные цифры не обрезаются.

Перед сдачей проверь главную, финансы, склад, заказы, гостей, настройки и рабочую панель всех ролей на одинаковую иерархию, контраст и формат цифр.
