# Правила агентов Territory CRM

Перед работой прочитайте `docs/AI_TEAM.md`, `docs/AI_TEAM_WORKFLOW.md`, `SITE_TREE.md`, `DEVELOPMENT_WORKFLOW.md` и соответствующий профиль из `.codex/team/roles/`.

Работайте только в заявленной области, сначала найдите первопричину, сохраняйте совместимость tenant/role/route, добавляйте проверку для исправленного сценария и фиксируйте результат. Не публикуйте production и не выполняйте необратимые операции без прохождения общего workflow.
